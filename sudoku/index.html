How to play & shortcuts

Fill every row, column and 3×3 box with the digits 1–9. Everyone gets the same puzzles each day; Easy and Medium can be finished with basic logic, Hard needs a bit more.

  • 1–9 place a digit · Shift + digit adds a note
  • Arrow keys move · ⌫ erases · N toggles notes · U undoes
陳Progress is saved in this browser only.
